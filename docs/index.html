Executive readout

Research status: partial, evidence-backed seed. Thirty-six app dossiers have been reviewed against official documentation. The other sixty-four rows are deliberately marked pending. The automated search-and-extraction pipeline is implemented, but it has not been run here because OpenAI and Tavily credentials were not supplied. Do not present the sample statistics as population-wide findings.

Patterns in the 36 reviewed apps

OAuth is common, but not sufficient

OAuth appears in 24/36 apps (66.7%). API key or token methods appear in 20/36 (55.6%). Authentication categories overlap, and OAuth does not guarantee open self-serve access.

Access models are mixed

13/36 self-serve (36.1%), 11/36 gated (30.6%), 10/36 mixed (27.8%), and 2/36 unknown (5.6%). Account roles, plan tiers, quotas and partner approval matter.

MCP evidence is sparse

Official MCP confirmed for 6/36 (16.7%), unavailable in one reviewed case, and unverified for 29/36 (80.6%). Unverified must not be interpreted as absent.

Buildability is mostly moderate

13/36 easy (36.1%), 19/36 medium (52.8%), and 4/36 hard (11.1%). A public API is only one part of toolkit readiness.

Credential and scope friction dominates

Credential/scope complexity was analyst-tagged as a blocker in 22/36 dossiers (61.1%). Workspace permissions and plan entitlements are separate blockers.

Quick wins need a product lens

Close, Intercom, GitHub and Cloudflare were assessed as P0 in this seed. This is a provisional integration-priority judgment, not a measured demand ranking.

All denominators are 36 reviewed apps. Auth and blocker labels are multi-label and overlap. The sample is purposive, not statistically random.

How the research agent works

  1. Input: load the 100-app research set from data/apps.json.
  2. Discovery: search API/authentication, credential/access and MCP sources separately.
  3. Extraction: OpenAI structures retrieved evidence into consistent fields; unsupported claims stay Unknown.
  4. Verification: a second pass performs fresh searches and compares selected claims; unverifiable claims are not counted as correct.
  5. Human review: resolve plan restrictions, admin approval, partner gates, scope and app-review requirements.

The current runner uses Tavily for retrieval and OpenAI for structured extraction. It does not currently call Composio SDK/MCP; that optional dogfooding step is not claimed as executed.

Run locally

From the repository root in Windows PowerShell:

py -3.11 -m venv .venv

.\.venv\Scripts\Activate.ps1

pip install -r requirements.txt

Copy-Item .env.example .env then add OPENAI_API_KEY and TAVILY_API_KEY to .env.

python agent/research_agent.py --limit 2 --verify-sample 1 for a small smoke test, then use --limit 100 --verify-sample 15.
